# 애니메이션 연결·조합 기준

인간과 호랑이·늑대·여우·사슴의 공통 클립 이름을 기준으로 합니다.
각 골격에 해당 체형으로 제작한 20개 Action이 들어 있습니다. 30fps이며 게임 연결 코드는 포함하지 않습니다.

## 클립 목록

| 구분 | 클립 | 길이 | 반복 |
|---|---|---:|---|
| 기준 자세 | Pose_Neutral / Pose_Turn_L45 / Pose_Turn_R45 / Pose_Crouch | 고정 자세, 2프레임 | 첫 프레임 사용 |
| 대기 | Idle | 2.0초 | 반복 |
| 걷기 | Walk | 1.0초 | 반복 |
| 뛰기 | Run | 0.8초 | 반복 |
| 제자리 방향 전환 | Turn_L90 / Turn_R90 | 1.0초 | 1회 |
| 공격 | Attack | 1.0초 | 1회 |
| 전체 점프 | Jump | 1.5초 | 1회 |
| 분할 점프 | Jump_Start / Jump_Air / Jump_Land | 0.3 / 0.8 / 0.4초 | 공중만 반복 |
| 웅크린 대기 | Crouch | 2.0초 | 반복 |
| 웅크려 걷기 | Crouch_Walk | 약 1.33초 | 반복 |
| 서기·웅크리기 전환 | Stand_To_Crouch / Crouch_To_Stand | 0.4초 | 1회 |
| 걷기 시작·정지 | Walk_Start / Walk_Stop | 0.4초 | 1회 |

인간 Run은 발마다 약 38% 접지 구간을 가지며 두 발이 함께 떠 있는 구간을 포함합니다.
동물의 걷기는 네 발의 위상을 나누고 뛰기는 앞·뒷다리 위상을 묶어 체형에 맞게 제작했습니다.
공격은 인간의 오른손 타격, 호랑이의 앞발·물기, 늑대·여우의 물기, 사슴의 머리·뿔 방어 동작입니다.

## 자세 연결 표

| 현재 자세 | 재생 순서 | 권장 혼합 시간 | 연결 기준 |
|---|---|---:|---|
| 대기 → 걷기 | Walk_Start → Walk | 0.14초 | 시작 클립 끝을 Walk 위상 0에 연결 |
| 걷기 → 대기 | Walk_Stop → Idle | 0.16초 | Walk 위상 0 근처에서 정지 진입 |
| 걷기 ↔ 뛰기 | Walk ↔ Run | 0.18초 | 발 위상을 맞추어 혼합 |
| 서기 → 웅크리기 | Stand_To_Crouch → Crouch | 0.10초 | 전환 클립을 끝까지 사용 |
| 웅크리기 → 서기 | Crouch_To_Stand → Idle | 0.10초 | 전환 클립을 끝까지 사용 |
| 웅크린 대기 ↔ 이동 | Crouch ↔ Crouch_Walk | 0.15초 | 같은 웅크림 높이 유지 |
| 웅크림 → 뛰기 | Crouch_To_Stand → Run | 0.18초 | 일어서는 전환을 거쳐 진입 |
| 지상 → 공격 → 복귀 | Attack → 직전 지상 자세 | 진입 0.08초 | 클립 93%부터 복귀 혼합 |
| 대기 → 90도 회전 | Turn_L90 또는 Turn_R90 → Idle | 0.12초 | root 회전을 처리한 후 대기 연결 |

공격 판정 참고 시점은 클립의 약 47%, 회복 구간은 약 82%입니다.
행동 판정과 충돌은 들어 있지 않으며 다른 작업에서 연결할 참고 정보입니다.

## 회전 보간

- 기준은 Pose_Neutral, 왼쪽 45도는 Pose_Turn_L45, 오른쪽 45도는 Pose_Turn_R45입니다.
- 입력 각도 -45 / 0 / +45에 오른쪽 / 중립 / 왼쪽 자세를 대응합니다.
- Pose_*는 절대 자세입니다. 절대 자세끼리 혼합하거나 중립 자세와의 차이를 계산해서 가산 자세로 사용합니다.
- 이 기준 자세에서는 발을 고정하고 몸통·목·머리 방향을 바꿉니다.
- 큰 방향 전환은 Turn_L90/R90의 발 디딤 동작을 사용합니다.
- Turn_*에는 root 본의 회전이 있습니다. 본 회전과 캐릭터 전체 회전을 동시에 중복 적용하지 마세요.
- 좌우 90도 클립의 최종 yaw를 캐릭터에 반영하고 root를 정리하는 처리는 사용하는 엔진에서 연결합니다.

## 점프 조합 두 가지

전체 동작을 재생할 때는 Jump 하나를 사용합니다.
이륙 20%, 정점 약 47.5%, 착지 76%를 기준으로 합니다.
root 본의 수직 궤적이 포함되어 있으므로 별도 물리 점프 궤적과 겹치지 않게 처리합니다.

물리 기반 점프를 연결할 때는 Jump_Start → Jump_Air 반복 → 지면 접촉 시 Jump_Land 순서로 사용합니다.
Jump_Air는 공중 자세를 유지하는 제자리 반복입니다.
준비·착지 동작의 root 수직 변화는 추출·제거하거나 엔진의 접지 기준에 맞게 반영합니다.
권장 자세 혼합 시간은 0.10초입니다. 전체 Jump와 분할 조합을 동시에 재생하지 않습니다.

## 이동 속도와 발 미끄러짐

모든 이동 클립은 제자리 동작입니다. 수평 이동은 다른 작업에서 연결합니다.
재생 배율 1.0의 시작 속도는 아래 값을 참고하세요.

| 골격 | 걷기 | 뛰기 |
|---|---:|---:|
| 인간 | 약 0.97m/s | 약 2.30m/s |
| 호랑이 | 약 0.74m/s | 약 2.79m/s |
| 늑대 | 약 0.60m/s | 약 2.27m/s |
| 여우 | 약 0.39m/s | 약 1.47m/s |
| 사슴 | 약 0.58m/s | 약 2.19m/s |

인간의 웅크려 걷기는 약 0.19m/s입니다.
다른 이동 속도에서는 재생 배율을 '목표 속도 ÷ 위 표의 속도'로 시작하여 조정합니다.
이 값은 스트라이드와 접지 시간에서 계산한 참고값입니다. 경사면, 이동 방향 변경, 혼합 구간의 발 위치는 실제 게임에서 추가로 다듬어야 합니다.

## 부품 교체와 사용 범위

인간은 HUM_7H_v1의 같은 본 이름·바인드 행렬을 공유합니다.
머리·얼굴·머리카락·의상 몸통·좌우 소매·골반·좌우 다리·장갑·신발·장비를 조합합니다.
같은 슬롯에서 파츠 하나를 고르고 얼굴·머리카락·장비는 지정된 겹침 슬롯에 올립니다.
의상 몸통과 소매는 같은 의상 종류를 사용하세요.

동물은 같은 종의 골격 안에서 몸통·목·머리·턱·귀·네 다리·꼬리를 교체할 수 있습니다.
사슴 뿔은 선택 파츠입니다. 다른 종의 부품은 관절 위치가 달라 바로 교환할 수 없습니다.
개별 파츠 GLB는 파츠와 바인드 골격만 포함합니다. 완성 조합 GLB에는 20개 동작이 포함됩니다.

## 확인 방법과 검증 범위

Characters/Human_Modular_Library.blend와 Animals/*_Modular.blend를 Blender에서 열고 골격을 선택합니다.
Dope Sheet의 Action Editor에서 원하는 클립을 고른 후 재생합니다. 기본 저장 상태는 A포즈/중립입니다.
Previews/Human_Motion_Sheet.png와 Previews/Tiger_Motion_Sheet.png에서 주요 동작의 자세를 비교할 수 있습니다.

원본은 첫 제작 단계의 로우폴리 모델과 애니메이션입니다.
Blender 메시·웨이트·순환 클립·GLB 재열기는 검증했으며 게임 내 카메라·지형·애니메이션 혼합 결과는 별도 확인이 필요합니다.
전체 검사 결과는 validation_report.json, 기계가 읽을 연결 정보는 animation_transitions.json을 참고하세요.
