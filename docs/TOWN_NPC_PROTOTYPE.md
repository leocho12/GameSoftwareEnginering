# 변경 마을과 주민 AI

사용자 `NPC_AI_Behavior_System_Design.md`의 인지 → 상황 판단 → Utility → 행동 → 기록 구조를 마을 주민에게 적용했다. 직업과 대사는 이번 요청에 맞춘 창작 확장이다. 원작 인물의 성격·사건·소속을 덮어쓰지 않는다. 주민 외형은 공용 임시 스프라이트이며 20종의 고유 아트가 추가된 것은 아니다.

## 마을과 조작

초기 위치 (3,3)를 중심으로 x/z -8~14에 광장·십자 도로·보급 상점·진료소·초소·숙소·구호 식당·창고를 배치한다. 건물은 충돌하며 내부 진입은 없다. 도로는 연결되어 있고 마을 바깥의 기존 연속 지형으로 이동 가능하다. NPC끼리/플레이어와의 몸체 충돌은 적용하지 않아 좁은 길을 막지 않는다.

- WASD 이동, 기존 조준/공격·획득·성장 유지.
- 가까운 NPC에게 F: 대화 시작/닫기. 1/2: 화면에 표시된 선택 실행. 거래는 반복 구매 가능하며 재화가 모자라면 거절한다.
- 초기 부품 10개 지급. 일반 상인: 회복약 구매 3, 판매 2. 의무관: 완전 치료 2. 구호 주민: 무료 체력 25, 45초 재사용.
- 사기꾼의 특가 상자는 4를 지불해도 물품이 없다. 거절하면 비용 없음. 무법자/악당은 2를 요구하며 거절하면 외부에서 적대할 수 있다. 지불 시 20초 동안 공격하지 않는다.
- 경비/사냥꾼에게 1: 현재 위치를 순찰 거점으로 지정. 명령 순응도×신뢰×존중이 .15 이상일 때 수락한다.
- 마을 안은 몹/적대 NPC에게 피해를 받지 않는 안전 구역이다. 마을 밖 적대 NPC는 플레이어 공격 대상으로 잡히며 제압할 수 있다. 일반 주민은 플레이어 탄환의 대상이 아니다.
- F6 구조 훈련은 유지한다. 훈련 중 마을 시뮬레이션도 정지한다.

## 설계 문서와의 연결

- 12 Traits: 기존 5개를 기반으로 위험 감수·탄약 절약·민간인 우선·후퇴·동료 지원·목표·자기보존을 확장했다.
- 인지: 10 거리 이내 적, 8 거리 이내 부상 동료를 시야선 검사 후 후보로 수집한다. 직접 인지는 .2초 간격, Utility 판단은 .5초 간격이며 NPC별 초기 시점을 분산한다.
- 상태: Idle / Alert / Combat / Retreat / Disabled. 상태는 행동 결과를 나타내며 별도의 장기 행동 트리를 구현한 것은 아니다.
- Utility 후보: 업무·순찰·공격·회피·도움·휴식. 점수차 .08 미만이면 행동 전환을 억제한다. 후보가 없으면 점수 -1.
- 이동: Utility와 분리한 40×40 로컬 BFS. 최대 약 1.3Hz 재탐색, 연속 좌표 이동·기존 충돌 사용.
- 전투: 사냥꾼/경비 등은 탄약을 소비해 몹을 공격한다. 탄약 소진/부상 시 귀환·휴식·재장전한다. 외부 몹과 밀착하면 반격 피해를 받는다. 몹의 본래 추적 목표는 여전히 플레이어이며 NPC 전용 추적·진형 전투는 없다.
- 지원: 부상 동료에 접근해 치료한다. 시야 내 관찰자는 구조 선호가 조금 증가한다. 변화는 기본 성격 +.1 이내이며 저항 값을 적용한다. 미션 단위 GA·전략 Population·소대 문화·영속 저장은 아직 미구현이다.
- 기억: 기존 문자열 이력은 16개, 의사결정용 중요 사건은 중요도/시간 기준 24개까지 유지. 제압된 NPC는 30초 후 거점에서 회복하며 적대가 해제된다. 리셋 시 주민·관계·기억도 초기화된다.

## 몹과 재생성

전체 풀을 16→32로 늘리고 사망 후 8초에 재생성한다. 마을 내부 및 플레이어 7 거리 안에는 생성하지 않고 22 거리 안의 이동 가능한 지점을 선택한다. 멀어진 몹은 기존 방식대로 플레이어 주변에 재배치한다. 마을 밖 사냥터는 계속 이어진다. NPC 사냥에 의한 처치는 플레이어 경험치/드롭을 주지 않아 자동 경험치 획득을 막는다.

## 로그와 검증

실행 파일 옆 `Profiles/npc_ai.jsonl`: 행동 전환·도움 성공·사냥 성공·상호작용을 기록한다. 영문 role/action 이름과 모든 Trait, 후보 점수, 인지 대상, 신뢰, 기억 개수를 포함한다. 최대 약 5 MiB에서 이전 파일 하나로 순환한다. 이벤트 로그이며 매 프레임 전체 NPC를 출력하지 않는다.

`tests/TownNpcTests.cpp`에 20명/8직업, 32몹, 건물 충돌·연결성, 거래 비용·사기 거절·무료 치료 재사용·안전 구역 검사를 작성했다. 링크 대상은 RpgGame.cpp / TownNpc.cpp / TownKnowledge.cpp / DollBehavior.cpp이며 Windows API 로그 경로를 사용한다. C++ 빌드·테스트·게임 실행은 이번 작업에서 하지 않았다. 실제 밀도·가독성·교전 난이도는 사용자 플레이 확인 후 조정한다.

주민 Update/인지·판단/경로 탐색의 누적 CPU ms와 호출·재탐색 수는 약 1 시뮬레이션 초마다 `performance_window`로 출력한다. `cpu_update_ms`에는 하위 구간이 포함되므로 합산하지 않는다. 이벤트 발생 시 같은 윈도우 중간값도 포함하며 집계에는 performance_window만 사용한다. 창 단위 로그 쓰기 자체는 Update 측정에서 제외된다.


## 자율 AI 확장 (최신 명세 1차 적용)

- F 대화 → H: 부상 주민에게 회복약 1개로 체력 50 지원. 주민은 지휘관 구조 기억과 신뢰·존중·빚을 얻고 이후 대화에서 회상한다.
- F 대화 → J: Needs/기억/지식 수/구조 담당과 점수 기여를 표시. J로 원래 거래 화면 복귀.
- K: 마을 무전 연결/단절. 단절해도 거리 6 이내 대화는 가능하다. 이미 전달된 정보는 유효기간까지 남는다.
- 무전 대상: 경비·사냥꾼·의무관·구호 주민. 전달된 정보에는 전달자, 직접/간접 구분, 원래 관측 시각, 신뢰도가 남는다.
- NPC는 알려진 위치로 이동하고 치료·사격 직전에 실제 거리/시야를 검사한다. 모든 NPC가 월드의 적 위치를 곧바로 공유하지 않는다.
- 입찰은 알려진 체력 55 미만 동료 대상. 연결된 구조자 간 담당 중복을 억제한다. 단절 그룹은 독립 판단하며 중복 구조가 가능하다.
- 구조 기억은 상대별 구조 가산점, 방향성 관계는 신뢰/존중/빚으로 저장한다. Reset/종료 후 보존하지 않는다.
- JSONL schema_version=2, decision은 NPC별 최대 2Hz. beliefs/relationships/memories와 help_contributions를 기록한다.
- beliefs.kind: 0=Enemy, 1=Ally, 2=Commander. memories.type: 0=CommanderSavedMe, 1=CommanderIgnoredMe(예약), 2=AllySavedMe, 3=SuccessfulMission, 4=FailedRescue. actor/target -1은 지휘관 또는 적용 대상 없음(사건 유형으로 구분).
- 위협을 무릅쓴 구조 실패는 구조 중 임계 체력 아래로 떨어질 때 기록한다. 시간 초과·경로 실패 전체를 포괄하는 실패 판정은 후속이다.
- 명령 수락 상태·task·선택 이유는 로그에 기록한다. Needs는 요약 값이며 Utility는 성향/위험/관계 항을 직접 사용한다.

### 사용자 실행 확인 항목

1. 상인 구매/판매와 WASD 사냥이 유지되는지 확인.
2. 부상 주민에게 H 지원 후 포션 감소, 체력 증가, 이후 감사 대사와 관계 로그 확인.
3. 부상 동료가 보이면 구조자 입찰·접근·치료와 AllySavedMe 기록 확인.
4. K로 통신을 끊고 멀리 떨어진 NPC의 간접 정보가 만료되는지 확인.
5. J 패널과 Profiles/npc_ai.jsonl에서 각 NPC의 지식·판단 근거 비교.

`tests/NpcMindTests.cpp`에 정보 만료, 전달에 의한 시간 갱신 금지, 방향성 관계, 상대별 기억 회상, 중요 기억 보존 검사를 작성했다. C++ 테스트는 실행하지 않았다.
