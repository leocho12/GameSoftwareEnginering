# 첫 RPG 레벨 — 외곽 사냥터

> 접지 그림자, 부품 지갑·재고·약탈, 대화 중 이동 정지, L 이야기 일지는 [ECONOMY_AND_STORY_STATUS.md](ECONOMY_AND_STORY_STATUS.md)를 따른다. 현재 실행은 순찰·지역 구조 사건까지이며 본편 중계소·수송차 퀘스트는 미구현이다.

> 2026-10-14 최신 기준: [BANDIT_PATROLS.md](BANDIT_PATROLS.md). 적은 3명씩 3개 야적 무리이며 성향에 따라 교전을 판단한다. 첫 목표는 레벨 3 → E로 아이템 2개 회수 → 마을 경비 F 복귀 보고다. 아래 이전 수치보다 이 기준을 우선한다.

## 현재 방향

사용자 결정에 따라 명일방주식 방어전, 배치 비용, 타일 단위 이동, 기존 튜토리얼 진행을 폐기하고 실시간 액션 RPG로 전환했다. 현재 실행 파일은 시작 즉시 첫 사냥터에 진입한다. 배경은 실제 3D, 시점은 고정 2.5D 쿼터뷰다.

스토리 없이 반복 사냥과 성장을 검증하는 레벨이다. 첫 목표는 레벨 3·전리품 2개 회수·마을 경비에게 복귀 보고이며 완료 후에도 탐험할 수 있다. 인간 지휘관 설정을 유지한다. 별도 인간 외형이 없어 조작 캐릭터는 4식 SD를 시험 외형으로 사용하며 UI에도 표시한다. 이를 원작 인물의 합류나 주인공 설정 변경으로 취급하지 않는다. 적은 원작 적 SD 3종을 야적 행동의 시험 외형으로 사용한다.

## 조작

| 키 | 동작 |
|---|---|
| WASD | 화면 방향을 기준으로 연속 이동, 대각선 속도 정규화 |
| 마우스 | 바닥 조준점 지정 |
| 좌클릭 유지 / Space | 조준 방향으로 연속 사격 |
| E | 1.5 거리 내 아이템 획득, 벽 너머는 획득 불가 |
| Q | 회복약 사용 |
| I | 가방·성장 규칙 표시. 전투는 계속 진행 |
| Esc | 정지 / 재개 |
| Enter (정지 또는 사망 시) | 같은 시드의 맵에서 처음부터 시작 |
| N (정지 또는 사망 시) | 새 랜덤 맵으로 초기화 |
| 휠 / F11 | 확대·축소 / 전체화면 |

재시작·맵 재생성은 경험치·레벨·아이템을 초기화한다. 화면 메뉴에서 이를 안내한다. 포커스 상실 시 입력을 비우고 일시정지한다. 저장 기능은 아직 없다.

## 기본 전투·성장

- 초기 체력 100, 공격력 14, 방어력 2, 회복약 3개.
- 조준 방향 사격: 거리 6, 공격 간격 0.4초, 가장 앞의 적 1기에 피해. 지형이 총탄을 차단한다.
- 야적 9명, 3명씩 3개 무리. 성향·위험·피격 여부로 교전을 판단하며 플레이어 처치 1회당 경험치 20을 즉시 지급한다. 중복 사망 보상은 없다.
- 다음 레벨 필요 경험치: `40 + 20 × (현재 레벨 - 1)`. 초과 경험치를 이월하고 여러 레벨 상승도 처리한다.
- 레벨마다 최대 체력 +20, 공격력 +3, 방어력 +1. 레벨업 시 현재 체력도 20 회복한다. 수동 스탯 배분은 이번 범위가 아니다.
- 성장 안전 상한은 100레벨이며 첫 목표는 3레벨이다. 경험치 합계와 현재 레벨 진행치를 구분해서 표시한다.
- 적 처치 시 회복약 또는 회수 부품을 바닥에 떨어뜨린다. E로 가방에 보관한다. 부품은 수집 수량만 관리하며 장비 제작·판매는 후속 범위다.
- 회복약은 최대 체력의 50%를 회복하며 체력이 가득 찼으면 소모하지 않는다.
- 전멸한 무리는 45초가 지나고 야영지에서 플레이어가 36보다 멀어졌을 때 다시 배치한다. 개별 적을 전투 중 보충하지 않는다. 오래된 바닥 아이템은 최대 128개까지만 유지한다.
- 사망 시 동일 맵 재시작 또는 새 맵 생성이 가능하다. 부활·저장·장비 강화는 아직 없다.

## 랜덤 맵 연결성

32×32 지형 정보를 내부 충돌·생성·적 탐색에 사용하지만 플레이어 이동은 실수 월드 좌표 기반이며 타일 선택·스냅 이동·격자 UI가 없다.

출발 구역을 비워 두고 암석·물을 무작위로 배치한다. 장애물 묶음을 추가할 때마다 출발점에서 전체 이동 가능 지면에 도달할 수 있는지 flood fill로 검사하고, 단절되는 배치는 되돌린다. 따라서 이동 가능 영역에 고립된 섬을 남기지 않는다. 물·암석·맵 바깥은 의도된 비이동 지형이다. 플레이어 폭 0.44에 맞춘 충돌 판정을 사용하며 좁은 길도 통과하도록 지면 중심 연결을 유지한다.

적은 플레이어까지의 거리장을 공유하고, 통과 여유를 검사해 모서리를 피한다. 지형 시드를 HUD에 표시하며 같은 시드로 재생성할 수 있다. 무한 청크 스트리밍은 이번 레벨 범위가 아니다.

## 렌더링

- 기존 원작 SD 대기·이동·공격과 부품 합성 깜박임 수정 유지.
- 원본 이미지 해상도와 창 해상도는 별개이며 SD를 픽셀 아트로 변환하지 않는다.
- 물: 시간에 따라 이동하는 파형·명암·반짝임을 지형 재질 셰이더로 계산.
- 불꽃: 빌보드 UV와 시간 기반 흔들림·폭·색·알파를 전용 셰이더로 계산. 불꽃 스프라이트 시트는 사용하지 않는다.
- 환경 그림자·후처리와 한글 HUD 유지. 불꽃은 장식이며 접촉 피해와 동적 광원은 이번 범위가 아니다.
- 바닥·도로·건물 재질의 최신 구현과 확인 항목은 [MAP_MATERIALS.md](MAP_MATERIALS.md)를 따른다. 1024×1024 재질 3종, 밉맵·삼선형·지원 GPU의 최대 8배 이방성 필터를 적용한다. 화면 해상도는 창의 실제 크기를 사용한다.

## 구조와 검증 상태

실행 코드: SimpleGame.cpp → RpgGame → Renderer / RenderEffects / CharacterAnimation. TutorialGame 및 TowerDefense는 과거 참고 파일로 남아 있지만 프로젝트 빌드와 실행에서는 제외한다.

코드 포맷, 프로젝트 XML·소스 참조 및 입력 연결을 정적으로 점검했다. 새 게임 빌드·실행과 실제 맵 이동, 사냥 밸런스, GPU 셰이더 검증은 아직 하지 않았다.

`tests/RpgGameTests.cpp`에는 64개 시드 연결성·통로 폭, 경험치 경계·연속 레벨업·능력치, 사망 중복 보상 방지, 아이템·회복, 정지·경계 충돌 회귀 검사를 작성했다. 테스트는 아직 실행하지 않았다. 게임과 별도로 RpgGame.cpp와 함께 C++17, UTF-8, PCH 비활성화, NDEBUG 미정의 설정으로 컴파일하는 CPU 전용 검사다.

사용자 확인 순서: WASD 이동 → 마우스 조준 사격 → 처치 경험치 증가 → E 아이템 획득 → Q 회복 → 레벨업 능력치 반영 → I 가방 → 사망 재시작 → Esc/N 새 맵 → 물결·불꽃 확인.

## 변경 마을 확장

초기 위치 주변 마을과 창작 주민 20명, 야적 3개 무리를 사용한다. F 대화·1/2 거래/상호작용·주민 Utility AI는 [TOWN_NPC_PROTOTYPE.md](TOWN_NPC_PROTOTYPE.md), 적 배치·판단·성장 목표는 [BANDIT_PATROLS.md](BANDIT_PATROLS.md)를 따른다. 적은 마을 안까지 추적·공격할 수 있으며 경계를 이동 제한으로 사용하지 않는다. 초기 부품은 10개다. 실행 검증 전이다.
