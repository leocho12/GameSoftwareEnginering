# 원작 SD 리소스 적용

2026-09-14. 추출·데이터 검증과 C++ 연결 코드를 작성했다. 게임 빌드·실행과 실제 화면 검증은 아직 하지 않았다.

## 추출 결과

사용자 제공 클라이언트에서 4식(4type), M4A1, UMP45, HK416, G11의 PNG·아틀라스·Spine 2.1.27 스켈레톤을 추출했다. 클라이언트 원본은 수정하지 않았다.

- `AssetsSource/GFL`: 추출 원본, 변환 JSON, 번들 및 파일 SHA-256을 기록한 source.json.
- `BaseProject_SE/SimpleGame/Assets/GFL`: 게임용 PNG·GFA1 5세트와 manifest.json. 총 약 36MB.
- 캐릭터별 대기(wait), 이동(move), 공격(attack), 쓰러짐(die), 승리(victory), 승리 반복(victoryloop)을 변환했다. R 접두어 스켈레톤은 추출·JSON 변환까지이며 게임에서 사용하지 않는다.

## 연결

| 위치 | 기존 슬롯 | 시험 외형 |
|---|---|---|
| 필드 | 알파 | 4식 |
| 필드 | 브라보 | M4A1 |
| 방어전 | 첫 번째 | UMP45 |
| 방어전 | 두 번째 | 4식 |
| 방어전 | 세 번째 | HK416 |
| 방어전 | 네 번째 | G11 |

위 배치는 외형 시험 편성이다. 원작 인물의 합류·초기 동료·역할을 확정하는 스토리 변경이 아니다. 인간 지휘관 설정은 유지하며 별도 인간 주인공 외형은 미정이다. 기존 슬롯 이름·능력치는 유지했다. 회복 슬롯도 동작 확인을 위해 원본 공격 모션을 사용하며 원작 능력을 재현한 것이 아니다.

필드는 대기·이동·임무 완료 승리, 방어전은 대기·실제 공격/회복 시점의 공격·전투 불능 동작을 연결했다. victoryloop는 데이터에 포함되지만 아직 호출하지 않는다. 퇴각은 쓰러짐을 재생하지 않는다. NPC·야생 개체·적은 기존 임시 외형이다.

## 처리 방식

원본 텍스처를 유지하고 뼈 변환·슬롯 순서·메시 가중치·FFD·아틀라스 회전 정보를 오프라인에서 30fps 삼각형 정점으로 변환했다. C++ CharacterAnimation이 이를 3D 공간에 그린다. 픽셀 아트 변환이나 이미지 생성은 하지 않았다. 프레임 사이 보간은 없고 원본에 없는 뒷모습은 추가하지 않았다. 좌우 반전 시 장비 비대칭도 반전된다.

확인한 다섯 자산을 대상으로 하며 IK, 비정상 블렌드 모드, 다른 상속 규칙은 오류로 중단한다. 범용 Spine 런타임이 아니다. 원본 슬롯 그림자는 제외하고 기존 월드 그림자 패스를 사용한다. 실제 화면에서 알파 경계·겹침·그림자를 확인해야 한다.

Visual Studio 빌드 후 PNG·GFA·manifest를 실행 파일 옆 Assets/GFL로 복사한다. Python·Node는 게임 실행에 필요 없다. 로드 실패 시 콘솔에 오류를 남기고 임시 스프라이트로 대체한다.

## 재생성

1. Python 환경에 UnityPy==1.25.3을 .asset-tools 대상으로 설치한다. 베이크는 Pillow, 검증은 Pillow·NumPy도 필요하다.
2. `python tools/extract_gfl.py <클라이언트의 Android/New 폴더> AssetsSource/GFL`
3. `node tools/convert_gfl.cjs <추출한 .skel 경로들>` — 실제 파일 목록을 전달한다.
4. `python tools/bake_gfl.py AssetsSource/GFL BaseProject_SE/SimpleGame/Assets/GFL`
5. `python tools/verify_gfl.py`

변환 도구 출처·수정 사항은 tools/vendor/gfSkel2Json/README.md, 라이선스는 같은 폴더의 LICENSE에 있다. 오프라인 변환에만 사용한다.

## 검증

5종 30개 클립의 파일 길이, 삼각형 구성, 좌표·UV·색상 범위와 프레임 변화를 검사했다. 프로젝트 XML과 소스 등록을 정적으로 확인했다. [부품 조립 미리보기](asset-previews/gfl-contact-sheet.png)는 게임 실행 화면이 아니다.

사용자 확인: 필드 이동, 방어전 배치·자동 공격·회복·전투 불능, 일시정지/배속, 건물 가림·그림자·투명도. 로드 실패 시 실행 파일 옆 Assets/GFL에 PNG 5개와 GFA 5개가 있는지 확인한다.


## 부품 깜박임 수정

사용자 실행 화면에서 SD 부품이 깜박이는 증상이 보고되었다. 기존 삼각형마다 미세한 깊이 차이를 주는 방식을 제거했다. 색상 패스는 깊이 검사를 유지하되 깊이 기록을 끄고 원본 슬롯 순서대로 합성한다. 이후 색상 기록 없이 알파 실루엣 깊이를 기록한다. 그림자 패스는 기존 실루엣 경로를 사용한다. 깊이 함수·깊이 기록·색상 기록 상태는 호출 전 값으로 복원한다.

코드 정적 검토만 완료했다. 실제 해결 여부는 같은 배치에서 대기·공격·좌우 반전, 인접 인형 겹침 및 건물 뒤 가림을 실행 확인해야 한다.

사용자 확인: 부품 깜박임 수정 후 실행 결과가 정상이라고 확인했다. 이는 사용자 플레이 확인이며 Codex가 별도로 빌드·실행한 결과는 아니다.
