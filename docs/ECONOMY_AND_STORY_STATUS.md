# 접지·대화·재화·스토리 진행 안내

2026-10-14 · 코드 반영 / C++ 빌드·게임 실행 미검증

## 캐릭터 접지

방향성 그림자의 광원을 실제 조명 방향 (-10,25,-8)과 맞췄다. 카메라 확대/축소로 그림자 방향이 달라지지 않으며 깊이 보정도 줄였다. 캐릭터와 같은 발 기준 좌표에 부드러운 접촉 그림자를 추가한다. 현재 평지·도로 상면 위 y=0.028에서 셰이더로 계산하며 화면 안의 모든 접촉 그림자를 한 번의 배치로 그린다. 지면 높이가 변하는 맵에서는 높이 조회가 추가로 필요하다.

그림자 맵의 자연스러운 측면 투영은 유지한다. 게임에서 발밑 접촉·나무/건물 그림자의 얼룩·확대/축소 시 품질을 확인해야 한다.

## 부품 재화

부품 1개를 교환 가치 1단위로 사용한다. 별도 현금·환율·무게 시스템은 이번 범위가 아니다. 플레이어 초기 부품은 10개, 상인 지갑은 20개, 무법자·악당은 2개, 다른 마을 주민은 8개다. 상인은 회복약 5개, 의무관은 치료 재료 5개를 가지고 시작한다.

| 거래 | 실제 변화 |
|---|---|
| 회복약 구매 | 플레이어 부품 -3 / 상인 +3 / 상품 -1 / 플레이어 회복약 +1 |
| 회복약 판매 | 플레이어 회복약 -1 / 상인 상품 +1 / 상인 부품 -2 / 플레이어 +2 |
| 치료 | 플레이어 부품 -2 / 의무관 +2 / 치료 재료 -1 |
| 사기·통행료 | 플레이어에서 해당 NPC에게 부품 4개·2개 이전 |
| 순찰 보고 보상 | 임무 지급처에서 플레이어에게 부품 5개, 한 번만 지급 |
| 사냥 전리품 | 회복약 또는 부품 1개, E로 회수 |

잔액·재고가 모자라면 거래하지 않는다. NPC끼리 돈을 자동으로 생성하거나, 회복 시 지갑·재고를 초기화하지 않는다. 구호 주민의 무료 응급 처치 규칙은 유지한다. NPC 경제와 기록은 현재 세션에서 유지하며 디스크 저장·상품 재입고·주민 직업 수입은 후속 범위다.

`TransferScrap`이 잔액 부족·자기 자신으로 송금·음수·정수 넘침을 거부한다. 거래·약탈·반환은 실제 지갑 사이 이전이며 임무 보상·드롭은 명시적인 신규 공급이다. 플레이어를 -1, 임무 지급처를 -2, 주민은 각 NPC ID로 기록한다.

## 자율 약탈과 대응

NPC Utility 후보에 `Rob`를 추가했다. 무법자·악당은 관측한 주민의 소지 부품, 거리, 자신의 공격성·빈곤, 주변 경비를 바탕으로 약탈을 선택할 수 있다. 경비·무법자·악당은 피해 대상에서 제외한다.

범행자는 피해자에게 접근해 거리 1.25 안에서 2초 동안 행동해야 하며, 시야·대화 여부를 다시 검사한다. 성공하면 최대 부품 3개를 실제 이전하고 피해자별 도난 내역을 보관한다. 30초 동안 재범을 제한한다. 피해자는 약 12초 동안 대피 행동을 우선하며 피해를 기억한다.

가까이서 목격한 NPC에게 범죄 정보가 전달되고 기존 지식 공유 규칙으로 전파된다. 경비는 알려진 범죄자를 추적·제압한다. 플레이어도 범죄 상태인 NPC를 마을 안에서 공격할 수 있다. 제압 시 도난 부품은 피해자에게 반환되며 두 번 반환되지 않는다. 모든 무법자가 항상 성공하거나 모든 경비가 전지적으로 범죄를 아는 구조는 아니다.

거래창에는 내 부품·상대 지갑·상품/의약 재고를 표시한다. NPC 머리 위에는 약탈·범죄 상태를 표시하고, 플레이어가 목격 가능한 가까운 사건은 알림을 준다.

## 대화 중 정지

대화 중인 마을 NPC는 이동·업무·공격·약탈 행동을 실행하지 않는다. 대화가 닫히거나 플레이어가 멀어지면 다시 판단·이동한다. 이미 피해를 받을 상황은 계속 처리하며 대화가 무적을 부여하지 않는다. 대화 상대를 새 약탈 대상으로 선택하지 않는다.

서사 동료도 대화 중에는 자율 출발 판단과 로컬 이동을 보류한다. 다른 NPC·세계 시간·사건 기한은 계속 진행된다. 급한 이동 임무로 대화를 할 수 없는 기존 동료는 이전처럼 귀환 후 대화하도록 안내한다.

## 지금 플레이 가능한 스토리

현재 게임은 원작 지휘관과 별개의 인간 그리폰 현장 지휘관이 변경 마을을 담당하는 창작 프롤로그다. [WORLD_AND_STORY.md](WORLD_AND_STORY.md)의 원작 사건·인물·장기 분기를 확정하거나 원문을 수정하지 않았다.

- **현장 순찰:** 레벨 3 → E로 아이템 2개 → 경비에게 F로 보고.
- **지역 구조 사건:** 미라·벨에게 F로 소식을 듣고, 1 직접 수색 또는 2 자율 판단을 선택한다. 직접 수색 수락 시 남쪽 초록색 표식에서 E로 구조한다. 동료는 독자적으로 출발할 수 있으며 귀환 후 F로 보고를 확인한다.
- **미구현:** 본편 중계소 복구·수송차 수색 퀘스트, 원작 주요 사건 연동, 회사 잔류/독립 분기.

상단 이야기 패널에 현재 상태와 다음 행동을 안내한다. **L 키 이야기 일지**에는 주인공의 역할, 순찰 진척, 직접 들은 무전·보고의 최근 5개, 구현 범위를 표시한다. 결과는 플레이어가 보고를 들은 뒤에만 보여 주며 V 진단 화면의 세계 진실과 구분한다. 일지 열기는 게임을 정지하지 않으며 Esc로 정지할 수 있다.

## 모니터링과 검증

`Profiles/economy.jsonl`에 거래·약탈·반환·보상을 이벤트별로 기록한다. 약 5 MiB에서 이전 로그 하나로 순환한다. 브라우저 스냅샷에는 NPC 지갑·재고·약탈 대상·범죄 상태, `economy.recent_events`, `story.status/next_step`을 추가했다. 기존 JSON과의 표시 호환성을 유지한다. 경제 판단·약탈 이동은 기존 NPC CPU 프로파일에 포함된다.

`tests/RpgEconomyTests.cpp`에 잔액 보존·부족·재고 소진·약탈 쿨다운·자동 약탈·경비 대응·반환 중복 방지·대화 정지/재개를 작성했다. `WorldSimulationTests.cpp`에는 대화 상대의 출발만 보류되는 검사를 추가했다. 이 C++ 검사는 실행하지 않았다. 브라우저의 재화·스토리 표시 검사는 통과했다. 그림자와 실제 범행 빈도·동선·밸런스는 사용자 실행 확인이 필요하다.
