# Resource 메시·애니메이션 게임 연결

2026-10-22. 별도 「그래픽 리소스 폴더 관리」 세션의 완료를 확인한 뒤 연결했다. 해당 세션의 원본 파일은 변경하지 않았다.

## 원본과 런타임

원본은 BaseProject_SE/Resource/Frontier_LowPoly_Kit_v1이다. Blender 원본·GLB·재질·스켈레톤·20종 자세/애니메이션과 Documentation/애니메이션_연결표.md를 보존한다.

게임은 범용 GLB 파서를 새 의존성으로 추가하는 대신, 전달된 GLB를 tools/resources/compile_pack.py로 변환한 **RPK1 버전1** 팩을 읽는다.

- 결과: BaseProject_SE/SimpleGame/Assets/World/kingdom.rpack
- 목록: 같은 폴더 manifest.json
- 65개 완성/환경 메시, 인간·동물8종×20클립 = 160클립, 약28.7MB.
- 256픽셀 재질10개를 2080×2080 공유 아틀라스에 패딩해 넣었다.
- 위치·노멀·색·UV·본 인덱스4개·웨이트4개, 인덱스 버퍼, 20fps 본 행렬 표본을 저장한다.
- 아틀라스와 모든 재질을 공유하므로 부위·재질별로 draw call을 나누지 않는다.
- .vcxproj의 CopyWorldResources가 빌드 결과 Assets/World에 팩과 목록을 복사한다. 옛 GF·구조 사건 파일의 자동 복사는 중단했다.

재변환은 저장소 루트에서 Python으로 tools/resources/compile_pack.py를 실행한다. numpy·Pillow가 필요하며 현재 Codex 번들 Python에서 확인했다. 이 작업은 게임 빌드가 아니다. 이어서 tools/resources/verify_pack.py로 변환 결과를 검사한다.

원본 팩은 이전 배경용으로 제작되어 일부 복식·소품에 현대적 흔적이 있다. 군용 조끼·지휘관 모자 조합 대신 주민/작업자 프리셋을 우선했다. 이번 연결은 새 원작 인물의 완성 모델을 제작하거나 모든 복식을 판타지 전용으로 다시 조형한 작업은 아니다. 원본 리소스 제작 세션과 분리해 관리한다.

## 렌더링과 애니메이션

WorldResources는 GLB의 좌표·계층·inverse bind·TRS·쿼터니언을 변환 도구에서 처리한다. C++은 본 행렬 표본을 보간해 4웨이트 스키닝한다. 스키닝한 동적 메시를 한 배치에 합쳐 업로드하고 그림자·본 화면에서 같은 결과를 재사용한다.

- Idle/Walk/Run/Attack을 현재 동작에 연결한다. 전투 불능 플레이어는 웅크린 자세를 쓴다.
- 클립 변경은0.16초 전환 보간, 방향은 최단 회전으로 보간한다.
- 인간 기본 걷기·뛰기와 동물 종별 스트라이드 기준으로 재생 속도를 조정한다.
- 원본 Jump·Crouch·Turn 등을 모두 팩에 보존했지만 현재 플레이에 점프/웅크리기 키와 별도 판정은 추가하지 않았다.
- 현재 조합은 완성 프리셋 단위다. 원본 신체 파츠의 런타임 편집·교체 UI는 후속 범위다.
- 리소스 팩 누락/손상 시 진단을 남기고 기존 임시 도형으로 대체한다. 정상 로드 시 새 메시 경로를 사용한다.

12×12단위 정적 청크의 지면·자연을 VBO/인덱스 버퍼로 캐시하고 마을은 마을별로 묶는다. 화면 영역 밖은 그리지 않고 멀어진 청크는 제거한다. 바닥은 평평하게 연결해 시각적 굴곡 때문에 캐릭터가 떠 보이거나 틈이 생기는 문제를 피한다. 지면을 그림자맵에 다시 그리는 비용은 생략한다.

## 프로파일과 검증

2026-10-28 프레임 끊김 조사와 스키닝 공유·배치 용량 재사용·청크 사전 생성·진단 로그 조정은 [FRAME_STUTTER_2026-10-28.md](FRAME_STUTTER_2026-10-28.md)를 참고한다. 독립 CPU 검사는 통과했으며 전체 게임 재빌드 후 성능은 미측정이다.

Profiles/resource_render.jsonl은 1초마다 현재 프레임의 메시 draw call·삼각형 수·정적 청크 수·환경 CPU 시간·스키닝/업로드 CPU 시간과, 그 사이 프레임들의 최대 CPU 시간·최대 메시 draw call·전체 신규 캐시 수를 기록한다. 5MiB에서 이전 파일1개로 회전한다. 이는 메시 배치 수이며 HUD·불꽃·화면 합성 등 모든 OpenGL 호출의 총합은 아니다.

확인한 것:
- 팩 전체65개 메시·160클립의 헤더/인덱스/경계/유한수/웨이트/필수 클립/SHA-256.
- Idle/Walk/Run/Attack의 처음·중간·마지막 표본을 실제 웨이트 스키닝하여 유한 좌표와 과도한 변형 여부 검사.
- 인간3프리셋의 bind 좌표와 inverse bind 행렬 합성 오차가 1e-5 미만.
- 프로젝트·필터 XML 및 코드 정적 검토.

C++ 빌드·OpenGL 실행·실제 FPS·접지·카메라·전환 품질은 **사용자 실행 확인 전**이다. 원본 제작 세션의 Blender 검사 통과를 게임 실행 성공이라고 표현하지 않는다.

## 2026-10-28 재개 점검

프로젝트/필터의 소스·헤더 연결과 리소스 복사 입력을 검사했다. 메시 팩65종·160클립과 브라우저 DOM 검사는 다시 통과했다. C++ 빌드·게임 실행은 수행하지 않았으며 실제 FPS·그림자·접지는 사용자 확인 대상이다.
