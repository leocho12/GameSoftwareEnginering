# 맵 재질 품질 개선

작성일: 2026-10-12 · 상태: 코드 적용 / 게임 빌드·GPU 실행 검증 전

## 원인과 변경

기존 맵은 저해상도 이미지 파일을 사용하는 구조가 아니라, 단순한 셰이더 노이즈와 색상으로 바닥·도로·건물을 표현했다. 특히 지면의 큰 명암 얼룩과 건물의 단순한 골·녹 무늬 때문에 화면 해상도와 관계없이 세부 표현이 부족했다. 장면 버퍼는 이미 창 해상도로 생성하므로 화면 전체 해상도를 무조건 올리는 대신 재질 자체를 개선했다.

- `RenderEffects` 초기화 시 자체 생성한 1024×1024 RGBA 재질 3종을 GPU에 올린다. 원작에서 추출한 환경 이미지가 아니라 이 프로젝트의 임시 재질이다.
- 잔디·흙: 흙 반점, 작은 잔디 잎, 세밀한 표면 입자. 넓은 지형에는 추가 색상 변화를 섞어 반복을 완화한다.
- 도로: 작은 자갈의 가장자리·명암과 흙 입자. 기존 도로 표시를 유지한다.
- 금속: 미세한 결·흠집과 녹 분포. 벽과 지붕의 면 방향에 맞게 좌표를 투영해 세로면에서 무늬가 늘어지는 문제를 줄인다. 금속 골의 가는 선에는 화면 픽셀 크기를 고려한 완화를 적용한다.
- 재질 하나는 월드 4×4 단위에 반복된다. 기본 밀도는 월드 1단위당 256텍셀이다. 나무·바위는 지면 재질과 분리해 기존 색상을 유지한다.
- 밉맵·삼선형 축소 필터·선형 확대 필터를 사용한다. 이방성 필터를 지원하는 GPU에서는 장치 한도와 8배 중 작은 값을 적용하고, 미지원 장치에서는 삼선형 필터로 표시한다.

## 비용과 로그

재질은 시작할 때 한 번 생성하고 종료할 때 해제한다. 매 프레임 생성하거나 맵 확장에 따라 추가하지 않는다. 기존 지오메트리를 그대로 사용하므로 draw call은 추가하지 않으며, 해당 재질의 픽셀에서 텍스처를 샘플링한다. 실제 GPU 시간 변화는 실행 프로파일링이 필요하다.

기본 이미지와 전체 밉맵의 RGBA8 데이터는 합계 약 16 MiB다. 드라이버 내부 비용은 별도다. 콘솔의 JSON 로그 `terrain_materials_initialized`는 `texture_count`, `texture_size_px`, `tile_world_units`, `anisotropy`, `estimated_gpu_bytes`, `cpu_initialize_ms`를 기록한다. `cpu_initialize_ms`는 CPU 생성·업로드 요청까지의 시간이며 GPU 완료 시간은 아니다.

## 사용자 실행 확인

1. 재빌드 후 마을 광장과 숲에서 바닥·도로·벽·지붕의 세부 표현을 비교한다.
2. 휠로 확대·축소하고 이동하며 먼 지면의 뭉개짐·깜박임과 재질 반복을 확인한다.
3. F11 전체화면에서도 선명도와 FPS를 확인한다. 캐릭터 원본 해상도는 이번 변경 대상이 아니다.

코드와 셰이더 연결은 정적으로 검토했다. C++ 빌드, 드라이버의 셰이더 컴파일, 실제 화면과 FPS 검증은 수행하지 않았다.
