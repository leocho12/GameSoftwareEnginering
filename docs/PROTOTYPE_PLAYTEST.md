# 프로토타입 실행 및 플레이 확인

현재 버전: 2026-09-10 실시간 타워디펜스 전환. 이전 턴제 조작을 대체한다.
상세 기획과 참고 출처: [명일방주 분석 및 구현](ARKNIGHTS_DEFENSE_PROTOTYPE.md).

## 실행

Visual Studio에서 `BaseProject_SE/SimpleGame.sln`의 SimpleGame을 시작 프로젝트로, x64 / Debug를 선택하여 빌드·실행한다. 이번 수정은 사용자 요청에 따라 Codex가 빌드하거나 실행하지 않았다.

기본 창은 작업 영역에 맞춰 최대 1920×1080으로 열린다. F11로 전체화면/창 모드를 전환한다. 1440p·4K 모니터에서는 전체화면이나 창 최대화로 실제 픽셀을 활용한다. Windows 스마트 앱 컨트롤 차단은 별도 보안 문제이며 이번 코드에서 보안 설정을 변경하지 않았다.

## 5분 이내 필수 동선

1. 작전 시작 → 노란 보급함 클릭 → 부품 확보.
2. 중계소 마당 클릭 → 방어전 진입.
3. 인형 카드 또는 1~4 → 녹색 배치 타일 → 바라볼 방향 타일 클릭.
4. 붉은 두 입구에서 나오는 적을 파란 거점에 도달하기 전에 저지·처치.
5. 방어 성공 후 필드 복귀 → 단말 클릭 → 복구 완료.
6. 결과창에서 자유 탐험을 선택하면 기존 28×24 필드·NPC 8명·야생 조우를 탐험한다.

첫 배치 예시(맵 좌표는 개발 확인용): 선봉 (8,3), 소총 (9,4)를 왼쪽 방향으로 배치하고, 비용이 모이면 방패 (11,4)를 왼쪽으로 배치한다. 수리 (11,6)는 위쪽 방향으로 배치하면 방패를 지원한다. 좌표축상의 방향이며 화면에서는 사선으로 보인다. 배치 전 금색 사거리와 방향선을 확인한다. 이 예시는 자동 승리를 보장하는 안내가 아니며 회귀 시나리오로도 작성했지만 아직 실행하지 않았다.

## 사용자 확인 항목

- Windows 100%/150%/200% 배율에서 글자 선명도와 마우스 위치 일치.
- 창 크기 변경·최대화·F11 전환 후 장면과 UI에 늘어짐·누락이 없는지.
- 타일 선택 시 초록 배치 가능 영역과 금색 방향별 사거리 표시.
- 지상/고지 오배치, 비용 부족, 중복 배치, 재배치 대기 중 배치가 거부되는지.
- 두 진입로 이동, 초과 저지 적의 통과, 방패 반격·소총 공격·수리 회복.
- Q 충전 소모, 지속 기술 종료, 퇴각 반환과 20초 후 재배치.
- Space 시 비용·적·재배치 시간이 멈추고, 지시는 가능한지. Esc 메뉴는 지시도 멈추는지.
- 아무것도 배치하지 않으면 거점 0으로 패배하고 재도전이 가능한지.
- 성공 후 부품을 보유한 채 필드로 돌아와 단말 복구가 가능한지.
- 야생 방어전 성공 후 조우 개체만 제거되고 탐험 위치가 보존되는지.
- 필수 동선의 실제 플레이 시간 5분 이내 여부.

## 선택적 CPU 회귀 검사

게임 프로젝트와 별도로 `tests/TowerDefenseTests.cpp`와 `BaseProject_SE/SimpleGame/TowerDefense.cpp`를 C++17 / UTF-8 / 예외 처리 활성화 설정으로 함께 컴파일한다. 미리 컴파일된 헤더 사용은 끈다. OpenGL 초기화가 필요 없는 assert 기반 검사이며, Debug처럼 NDEBUG가 정의되지 않은 구성으로 실행한다. 이번 작업에서는 실행하지 않았다.

## 세계관 반영 확인

시작 화면에서 별도 그리폰 인간 지휘관이라는 신분과 주민 연락망 복구 목적을 확인한다. NPC 대화에는 오염·전쟁 이후 생활과 인형의 기억·동료 보호가 반영되었다. 단말 복구 후 수송차 수색 요청은 다음 임무 예고이며 현재 실행 가능한 퀘스트가 아니다. 원작 후반 인물의 정체와 최종 사건이 초반 대사에 노출되지 않는지 확인한다. 상세 기준은 [WORLD_AND_STORY.md](WORLD_AND_STORY.md)다.

## 원작 SD 플레이 프로토타입 진입

Visual Studio에서 BaseProject_SE/SimpleGame.sln을 열고 x64 구성으로 빌드·실행한다. 시작 화면에 두 경로가 있다.

- **전체 튜토리얼 시작**: 기존 부품 회수 → 중계소 방어 → 단말 복구 → 자유 탐험. Enter/Space도 가능하다.
- **방어전 바로 체험**: 버튼 또는 D. 복구 부품을 가진 채 방어전으로 바로 진입한다. 비용 50과 전술 정지 상태로 시작하므로 4기 모두 배치를 준비할 수 있다. 카드 → 배치 타일 → 방향 타일 순서로 누른다. 배치 확정 전에도 실제 SD 외형이 나타난다. Space/전투 재개로 적 진입을 시작한다.

카드에는 UMP45·4식·HK416·G11 외형 이름을 표시한다. 능력은 기존 시험 역할이며 원작 캐릭터의 능력 재현을 뜻하지 않는다. 패배 시 재도전하면 체험 비용과 전술 정지를 복원한다. 승리하면 필드로 돌아와 단말 복구·자유 탐험까지 이어진다. 체험 경로는 전체 튜토리얼 5분 평가에서 제외한다. 메뉴의 레벨 다시 시작은 첫 화면으로 돌아간다.

이번 변경은 코드와 입력·상태 전환을 정적으로 검토했으며 게임 빌드·실행은 하지 않았다. 시작 버튼 두 개, D 키, 배치 미리보기, 재개, 패배 재도전, 승리 후 단말 복구를 확인한다.
