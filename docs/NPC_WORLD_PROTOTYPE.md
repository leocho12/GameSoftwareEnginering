# 자율 월드 NPC 첫 프로토타입

작성: 2026-10-01. 상태: 코드 반영 / 정적 검토. C++ 빌드·테스트 실행·게임 플레이는 사용자 확인 전이다.

## 반영 내용

기존 주민 20명 및 사냥은 유지하고 미라·벨 시험 동료 2명을 추가했다. 기지 시작점보다 남쪽에 있으며, 기존 주민과 같은 임시 공용 외형을 쓴다. 둘은 배열 인덱스와 분리된 안정 ID 1001/1002로 관리한다. 플레이어 ID는 1이며 기존 주민의 ID 체계는 아직 이관하지 않았다.

`WorldSimulation.h/.cpp`는 OpenGL/Windows/PCH에 의존하지 않는 코어다. `Brain`은 Belief/Desire/Intention을 소유하고 `Evaluate`가 성향·관계·능력·위험·기억 점수를 계산한다. 선택된 목표는 Task 상태와 예약 사건으로 실행한다. `RpgWorld.cpp`는 기존 MoveNpc를 이동 어댑터로 사용하며, `RendererWorld.cpp`는 대화/진단 정보를 표시한다.

구현 단위는 첫 사건 하나에 맞춘 작은 코어이며 설계서의 모든 클래스를 별도 Manager로 만든 상태가 아니다. 현재 함수와 데이터 경계를 후속 모듈 분리의 기준으로 사용한다.

## 조작과 기본 흐름

- WASD/사격/기존 주민 거래는 유지된다.
- **F**: 가까운 미라·벨과 대화/종료. 출발·복귀 이동 중에는 대화를 거절한다.
- 대화 중 **1**: NPC 출발 전 직접 수색 수락. 남쪽 길의 초록색 표식(월드 3,18)에서 **E**로 구조한다. NPC가 먼저 출발하면 현장 참여 경로는 닫힌다.
- 대화 중 **2**: 자율 판단에 맡김. 세계는 이 선택을 하지 않아도 진행한다.
- **V**: 월드 AI 디버그. **B**: 미라/벨 선택 전환. **T**: 디버그가 열렸을 때 게임 시간 10분 진행.
- **K**: 기존 무전 스위치. 신호 수신 전 끄면 두 동료가 실종 사건을 자동 인지하지 않는다. 복구 시 재전송으로 인지한다. 이미 알게 된 장기 사건은 잊지 않는다.
- Esc 일시정지/F6 독립 훈련/플레이어 전투 불능 중 본 월드 진행은 중단된다.

실제 게임 갱신 1초=월드 1분. 오전 8시 시작, 5분 뒤 신호, 30분부터 목표 평가. 준비 후 실제 출구까지 걸어간 다음 원격 이동 60분→수색 90분→귀환 60분을 거쳐 복귀한다. 기본 방치 경로는 대략 실제 4~5분이다. 실제 성능/경로에 따른 소요 시간은 실행 확인 필요하다.

T는 로컬 이동을 순간 완료시키지 않는다. 출구 이동 중 시간을 반복해서 건너뛰면 출발 제한 시간을 넘겨 실패할 수 있다. 출구를 통과해 원격 상태가 된 뒤 원정 시간 확인에 사용한다.

## 사건·결과·정보

사건 기한은 2게임일(2880분). 아무도 해결하지 않아도 만료된다. 기본 데이터에서는 두 동료가 구조를 선호하고, 벨의 미라 신뢰를 낮추면 기지 유지 점수가 앞선다. 결정과 결과 모두 현재는 결정적 계산이며 난수를 사용하지 않는다.

구조 결과는 함께 수색 중인 인물의 전투/전술 역량과 난이도를 비교한다. 둘이 참여하면 성공, 미라 단독 기본값은 부분 성공과 부상으로 연결된다. 결과에 따라 지역 구조 인원·물자·당사자의 체력·관계·기억이 변한다. 부상은 기지 휴식 중 회복한다. 영구 사망은 이 첫 사건에서 생성하지 않는다.

누가 출발했는지와 실제 결과는 개발자 디버그에서 볼 수 있다. 일반 플레이어는 접근 대화로 신호를 알고, 귀환 보고를 받아야 NPC 수색 결과를 안다. 보고를 전달받은 NPC는 직접 구조했다고 주장하지 않고 전언으로 답한다. 플레이어 직접 구조 후 다시 대화하면 지휘관의 보고가 기억/관계에 반영된다.

같은 사건 해결·출구 도착·자원 반환 요청을 반복해도 중복 적용되지 않도록 상태를 확인한다. 지역 효과 Journal은 sequence별 중복을 제거한 재생 검사를 제공한다. 전체 월드/NPC replay 및 영속 저장을 완성한 것은 아니다.

## 데이터와 프로젝트 연결

`BaseProject_SE/SimpleGame/Assets/AI/`:

- `actors.tsv`: ID/이름/기지 좌표/성향/스킬/잔류 우선도/관계 대상·신뢰.
- `goals.tsv`: 목표 점수의 성향·자율·관계·능력·위험·복종 가중치.
- `event.tsv`: 시간·기한·원정 구간·초기 물자·난이도·출구/수색 위치.
- `dialogue.tsv`: 한국어 대사 키와 내용.

탭 구분 UTF-8, `#` 주석. 로더는 열 수, ID 중복/예약 ID/관계 참조, 필수 설정, 범위, 시간 순서, 필수 대사를 검사한다. 오류 시 화면에 파일명/행/사유를 표시하고 서사 AI만 비활성화한다. 기존 게임은 유지한다.

문서의 JSON 제안 대신 첫 평면 데이터에는 TSV를 선택했다. 새 외부 JSON 의존성이나 임시 JSON 파서를 추가하지 않고 표준 라이브러리로 엄격하게 검증할 수 있기 때문이다. 중첩 GOAP/HTN 데이터 도입 단계에서는 JSON 로더를 다시 검토한다. TaskSequence와 허용 행동은 현재 코드의 유한 상태 규칙이며 데이터화된 범용 플래너가 아니다.

Visual Studio 빌드 후 AI 데이터 4개를 실행 파일 옆 Assets/AI로 복사하도록 프로젝트에 등록했다. 데이터 수정 후에는 다시 빌드해 복사하거나 실행 폴더의 사본을 갱신해야 한다.

## 진단과 검증 상태

`Profiles/world_ai.jsonl`: 사건 생성/수신, 결정, 협력 요청·수락/거절, 준비, 출발, 수색, 해결, 부상, 관계 변화, 귀환 기록. 5 MiB 이후 이전 파일 하나로 회전한다. seed/sequence/game_minute/actor_id/event_id, 목표 점수/기여/사유, CPU 갱신·판단 시간과 큐 크기를 기록한다.

점수 배열은 [기지 유지, 구조, 회복], 구조 기여 배열은 [성향, 관계, 스킬, 위험, 기억]이다. outcome은 0 미확인/1 성공/2 부분 성공/3 실패. sequence는 Reset마다 초기화되며 region_initialized가 새 회차의 시작이다. 로그 CPU 값은 기록 시점의 최근 측정값이며 합산 성능 통계가 아니다.

`tests/WorldSimulationTests.cpp`에 방치 성공, 무전 차단/복구, 기한 만료, 직접 구조, 낮은 신뢰에 따른 잔류, 부분 성공/부상, 중복 해결/환급 방지, 지역 효과 replay, 갱신 분할, 로드 실패 검사를 작성했다. 이 파일과 WorldSimulation.cpp를 C++17/PCH 없이 연결하며 렌더러는 필요 없다. 선택 인수로 Assets/AI 경로를 전달할 수 있다. **이번 작업에서는 컴파일하거나 실행하지 않았다.**

정적 점검 대상: 코드 포맷, 프로젝트 XML/소스 등록, TSV 구조·참조·필수 키, 기존 조작의 연결. 실제 화면 겹침/출구 경로/명중·프레임 비용은 사용자 실행으로 확인해야 한다.

## 후속 단계와 한계

GOAP, HTN, 범용 EventBus/Blackboard/Contract-Net, InfluenceMap, 본격적 CBR, 감정/Mood, Storylet, GA, 3단계 AI LOD, 세력 AI, 전체 저장/불러오기는 아직 구현하지 않았다. 기억 회상은 동일 태그의 강도·시간 감쇠를 사용하며 가중 다중 태그 유사도는 후속이다. Belief는 실종 신호/결과 중심이며 잘못된 위치 보고·모순 해결은 아직 없다.

기존 주민 AI와 새 동료 Mind의 통합 이관도 후속이다. 새 동료는 기지와 원격 임무용이며 현재 일반 몹과의 로컬 전투 대상에는 포함되지 않는다. 전체 게임 전투를 대체하지 않는다. 종료/Reset 시 월드 상태는 초기화된다. 중요한 세계 사건명이나 원작 연도·생존 결과를 새로 확정하지 않았다.
