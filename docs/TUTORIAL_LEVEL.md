# 튜토리얼 레벨 — 침묵한 중계소

갱신: 2026-09-10. 사용자의 최신 요청으로 격자 턴제 전투를 실시간 타워디펜스로 교체했다.

필수 흐름은 **보급 부품 확보 → 중계소 방어 → 단말 복구**이며 목표 시간은 5분 이내다. 전투 후 기존 2.5D 쿼터뷰 필드로 돌아온다. 결과창의 자유 탐험은 필수 플레이 시간에서 제외한다.

현재 규칙·수치·아트 처리·원작과의 차이는 [명일방주 분석 및 방어전 기획](ARKNIGHTS_DEFENSE_PROTOTYPE.md)을 따른다. 조작과 사용자 검증 항목은 [플레이 확인 문서](PROTOTYPE_PLAYTEST.md)에 있다.

28×24 필드의 지형·NPC·상호작용은 유지한다. 전투는 같은 카메라 표현을 사용한 별도 11×7 방어 보드로 전환하며, 조우 장소를 그대로 전장으로 사용하는 방식은 아직 구현하지 않았다. 무한 생성 월드·본편 퀘스트 확장은 후속 작업이다.

스토리는 소녀전선 1편 세계관 안의 별도 인간 지휘관이라는 확정 방향을 유지한다. 임무명·인형 역할명·야생 적의 구성은 프로토타입용 임시 설정이며 원작 사건으로 취급하지 않는다.

## 세계관·서사 적용 (2026-09-10)

[사용자 제공 요약](../소녀전선_최종정리.md)과 [게임 적용 기준](WORLD_AND_STORY.md)을 따른다. 플레이어는 원작 주인공과 별개의 그리폰 인간 지휘관이다. 임무의 이유는 주민과 보급 수송대의 연락망 복구이며, 전쟁·오염 이후 현장의 책임을 NPC 대사로 전달한다. 인형의 소체 수리를 기억의 무조건적 복원으로 설명하지 않는다.

복구 후 '돌아오지 않은 수송차' 수색 요청이 대사로 예고된다. 수색 퀘스트·보상·선택 분기는 아직 구현하지 않았다. 정확한 연도·지역명·적 소속은 지정하지 않으며, 원작 후반 비밀을 초기 대사에 넣지 않는다.
