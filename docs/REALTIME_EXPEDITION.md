# 실시간 탐사·생존·구조 시스템

2026-10-28 사용자 결정: **WASD·마우스 실시간 조작, 고정 2.5D 쿼터뷰·3D 리소스, 현재 소설 기반 세계관을 유지하고 게임 시스템을 전환한다.** Gobboree의 행동 기반 시간 진행을 그대로 복제하지 않는다. 성인 콘텐츠·관계·신체 시스템은 채택하지 않는다.

이 문서의 수치·사건·주민 활동은 현재 게임용 각색이다. 소설 원문에 있는 공식 규칙이나 Gobboree의 동일 구현이라고 주장하지 않는다. 실제 빌드·플레이 확인 여부는 아래 검증 기록과 구분한다.

## 이번에 연결한 흐름

`준비 → 단서 수집 → 실종자 접촉 → 실제 이동으로 호위 → 아플리아 외곽 귀환 → 경비에게 보고`가 현재 첫 의뢰다. 종전의 마을 5곳 방문/마수 12마리 처치 보고는 활성 목표에서 제거했다. 마을 방문·처치 통계 자체는 모니터용으로 남는다.

- 출발지 경비에게 **F → 3**: 하멜른 사냥꾼의 실종 단서.
- 카디낙 길목 상인에게 **F → 3**: 목격 단서.
- 카디낙 동쪽 도로의 흩어진 짐 근처에서 **E**: 현장 단서.
- 서로 다른 단서 2개를 모으면 현장 안내가 열린다. 중복 대화는 단서를 늘리지 않는다.
- 카디낙~하멜른 사이 도로 북쪽의 기존 주민을 찾아 **E** 또는 대화 **1**로 호위한다. 직접 발견한 경우 단서 수로 접촉을 막지 않는다.
- 대상은 같은 주민 ID를 유지하고 길찾기로 이동한다. 새 복제 인물을 만들거나 플레이어에게 순간이동하지 않는다.
- 14거리 이상 떨어지면 그곳에서 대기한다. 마지막으로 시야 안에서 확인한 위치를 일지 안내에 보존한다. 돌아가 **E**로 재개한다.
- 플레이어와 동행자가 모두 아플리아 외곽 광장 5거리 안에 들어오면 귀환 상태가 된다.
- 출발지 경비에게 **F → 3**으로 보고하면 은화 12와 구조 실적을 한 번 지급한다. 대화 열기만으로 보상하지 않는다.
- 전투 불능 대상은 회복약 1개로 일으킨 뒤 호위할 수 있다. 플레이어 HP가 0이면 탐사 실패다.

의뢰 상태 소유자는 `expedition::RescueQuest`, 실제 인물의 소유자는 기존 `npcs`다. `WorldSimulation`의 옛 스토리·구조 어댑터를 재활성화하지 않는다.

## 조작

| 입력 | 동작 |
|---|---|
| WASD / 마우스·좌클릭·Space | 기존 실시간 이동 / 공격 |
| G 누르기 | 기력을 쓰며 달리기 |
| C 누르기 | 느린 은신 이동, 시각 감지 거리·발소리 감소 |
| E | 근처 현장 조사 / 호위 시작·재개 / 전리품 줍기 |
| F, 1~5 | 대화 열기·닫기와 상황별 선택 |
| Q / B / T | 회복약 / 식량 / 식수 |
| R | 추격이 없는 마을에서 휴식 시작·중단 |
| I / L | 보급품·능력치 / 의뢰 일지 |
| M 또는 V / J | 기존 개발용 마을 통계 / AI 정보 |
| Esc | 세계 시계와 시뮬레이션을 함께 일시정지 |
| 실패/정지 중 Enter / N | 같은 seed / 새 seed로 초기화 |

가방·일지를 읽거나 대화하는 동안 플레이어 이동과 공격 입력은 차단하지만 **세계는 실시간 진행**한다. 대화 상대만 멈춘다. 안전하게 읽으려면 Esc를 사용한다. 가방·일지를 열 때 기존 이동/자동 공격 키 상태를 해제한다.

## 시간과 생존

- 시뮬레이션 초(`RpgGame::time`)와 세계 분(`Clock::minutes`)을 분리한다. 기존 전투·기억·소문 만료의 초 단위를 무작정 변환하지 않는다.
- 시작 1일 08:00, 현실 시뮬레이션 1초당 세계 2분. 하루는 시뮬레이션 12분이다. 실제 렌더 지연 때문에 잃은 시간을 자동으로 모두 따라잡는 기능은 추가하지 않았다.
- 7개 시간대: 깊은 밤 00:00, 새벽 04:00, 아침 07:00, 한낮 11:00, 오후 15:00, 해질녘 18:00, 저녁 20:00.
- 허기·갈증·피로는 0~100. 기본 세계 분당 증가량 .020/.030/.022. 한낮 갈증 ×2.2, 달리기 피로 증가량 .10.
- 60부터 need 페널티, 85부터 큰 페널티. HP와 need 페널티로 condition을 계산하고 기력 상한을 정한다.
- 공격 기력 10, 달리기 초당 18. 평소 초당 7 회복, 휴식 초당 18 회복.
- 기력 12 미만으로 달리기가 중단되면 30까지 회복해야 재개한다. G를 누른 채 저기력 경계를 오가며 속도가 매 프레임 흔들리지 않게 한다.
- 식량 허기 -45, 식수 갈증 -55. 각 3개로 시작하고 최대 6개까지 구매한다. 필요 수치가 5 미만이면 소비하지 않는다.
- 휴식은 피로를 세계 분당 .8 감소시킨다. 허기·갈증 60 미만일 때 초당 HP 1을 회복하며 HP 0을 부활시키지 않는다.
- 높은 허기·갈증·피로는 시간에 따른 HP 손실도 만든다. 잔여 소수 피해/회복을 상태가 보존하므로 작은 서브스텝마다 정수로 버려지지 않는다.
- 안전한 마을 밖이나 실제 보이는 가까운 추격자가 있으면 휴식을 시작하지 못한다. 이동·공격·가까운 위험은 휴식을 중단한다.

## 일과와 거래

- 근무·식사·수면 일과와 실제 걸어갈 활동 장소를 분리한다. 기존 역할·성향·전투·치료·도난·관측 우선순위를 유지한다.
- 식사 07:00~07:30, 11:00~11:30, 18:00~18:30. 20:00~04:00 일반 주민은 수면. 경비 일부는 야간 근무한다.
- 일과보다 알려진 전투·위험·심한 부상·지원 요구가 우선한다.
- 상인/치유사는 근무 중이고 자기 일터 근처이며 여행 중이 아닐 때 서비스를 제공한다. 단서 문의는 거래와 별개다.
- 전령의 진행 중 여행은 일과가 바뀌어도 도착까지 계속한다. 도착 후 현지 식사/휴식 장소를 다시 정한다. 소문은 실제 이동·대면·시야 조건으로만 전달한다.
- 상인 대화 **4**는 식량, **5**는 식수(각 은화 1). 기존 회복약 구매/판매는 1/2다. 플레이어 지갑·상인 지갑·재고·휴대 상한을 검사하고 실제 이전한다.
- 보급품 재고는 한정된다. 이번 변경에 공급망·자동 재입고·범용 제작 트리를 추가한 것은 아니다.

## 감지·경보·성장

- 밤에는 마수 시야가 짧아지고, 은신은 시야 거리를 .55배로 줄인다. 일반/달리기/은신 발소리 반경은 3/8/1.5, 공격 소리는 10(은신 공격 4)이다.
- 소음은 위치와 만료 시각을 가진다. 들은 마수는 그 위치를 조사한다. 듣기만 했는데 플레이어의 이후 실시간 위치를 받지 않는다.
- 실제 지역 관찰자가 4개 교역로 중 자기 지역 경보를 올린다. 경보는 0~4단계이며 감지 거리와 추적 범위에 영향을 준다. 다른 지역으로 즉시 방송하지 않는다.
- 적은 현재 시야와 기억한 위치를 구분한다. 정확한 위치를 동료에게 전할 때 근처 같은 무리와 실제 시야를 확인한다.
- 마지막 사건 후 10초 조용하면 경보가 초당 1씩 줄어든다. 수치를 0~100에 제한한다.
- 처치 XP·레벨별 자동 HP/공격/방어 성장은 제거했다. 무기 숙련은 유효 처치 실적에 따라 증가하고, 3승부터 전투자 perk(방어 보정)를 갖는다. 구조 실적도 별도로 기록한다.
- 플레이어와 NPC의 마수 피해는 `DamageMonster` 한 곳을 거친다. 죽음 전환에서만 재생성 시간을 다음 새벽까지로 정하고 플레이어 실적/전리품을 한 번 처리한다. 종전 3초 반복 생성은 제거했다. 실제 배치 안전 검사는 기존 생성 소유자가 유지한다.
- 이동 속도와 3D 보행 클립 속도는 같은 실제 속도를 사용한다. 동행자는 기본 플레이어 보행 속도로 따라오지만 달리면 뒤처질 수 있다.

## 코드와 검증

- `ExpeditionRules.h`: 그래픽과 분리된 시계·생존·경보·의뢰·성장 규칙.
- `RpgExpedition.cpp`: 현재 지도/NPC/거래/입력과의 연결. Visual Studio 프로젝트와 필터에 추가했다.
- RpgGame/TownNpc/RpgBandits: 실제 실행 루프·일과·감지·공통 피해 처리.
- Renderer/RendererTown/RendererWorld/WorldResources: HUD·대화·일지·속도 연동.
- GameMonitor와 모니터 페이지: 생존·시간·의뢰·경보·일과 상태 표시. 이전 스냅샷의 생존 필드 누락도 허용한다.

추가/갱신 검사 소스:

- `tests/ExpeditionRulesTests.cpp`: 시계/정지 입력·날짜·need 정수 잔여·휴식·경보 분할시간·단서 중복·보상 상태.
- `tests/ExpeditionWorkflowTests.cpp`: 실제 RpgGame 실시간 진행/정지, 서로 다른 단서, 호위 ID/이동/낙오, 보고 보상 1회, 휴식/초기화.
- 기존 RPG/마수/월드 검사는 폐기된 XP/방문 보고/3초 재생성 기대를 새 규칙으로 변경하고, 지형 연결·충돌·재화/소문 검사는 보존했다.
- 독립 RPG 검사 링크에는 **RpgExpedition.cpp**도 포함해야 한다. 간단한 순수 규칙 검사는 ExpeditionRulesTests.cpp 단독 C++17 실행 파일로 만들 수 있다.

**C++ 빌드·검사 실행·게임 플레이는 미수행이다.** 저장소 지침에 따라 사용자 담당으로 남긴다. Tree-sitter C++ 구문 검사와 XML/연결 정적 검사는 C++ 타입 검사나 링크 성공을 보장하지 않는다. 실행한 모니터 DOM 검사는 게임 동작의 증거가 아니다.

플레이 확인 순서: 시작 경비 단서→카디낙 상인 단서→짐 조사→부상자 E→보행 호위/달리기 낙오→귀환/보고 두 번→은화 한 번 지급, 낮밤 전환/영업 중단, 식량·식수 소진과 휴식, 소음 조사와 지역 경보, 정지 중 시간 고정을 확인한다.

## 남은 범위

Gobboree의 모든 기능을 완전히 이식한 버전은 아니다. 일반 장비/양손/가방 인스턴스, 범용 제작, 시설 투자, 배경 선택, 여러 의뢰·엔딩, 미니게임, 영속 저장은 아직 미구현이다. 이번 전환은 사용자가 선택한 **실시간 생존·일과·경보·구조 의뢰**의 연결이다. 수치 균형과 UI 배치는 실제 플레이로 확인해야 한다.
